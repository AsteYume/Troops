## 1. 개요

### 1.1 한 줄 소개
병사를 적재적소에 배치하고 능력을 활용하여 적은 수의 아군으로 전투를 유리하게 풀어나가는 게임


### 1.2 게임 컨셉
- 2차대전 배경 타일그리드 전략 게임
- 유닛은 보병과 중화기 위주
- X-COM 처럼 유닛 단위 전투에 집중


### 1.3 기본 정보
| 항목 | 내용 |
|---|---|
| 장르 | 사각 그리드 턴제 전략 시뮬레이션 |
| 플랫폼 | PC, 싱글 플레이 |
| 엔진 | Unity 3D |
| 개발 규모 | 1인 개인 프로젝트 |
| 진행 기간 | 2026-11-06 ~ 2026-11-24 (13회) |
| 1스테이지 플레이 시간 목표 | 10분 |

### 1.4 레퍼런스 게임

| 게임 | 참고하는 점 |
|---|---|---|
| 슈퍼로봇대전 30 (기준) | 공격 범위, 그리드 시스템 |
| X-COM | 시야, 전투 단위 | |
| 컴퍼니 오브 히어로즈 | 엄폐, 무기 |

### 1.5 범위에서 제외하는 것

- 전투 애니메이션 컷신 (맵 위 간단한 이동, 피격 표시, 데미지 숫자로 대체)
- NavMesh (칸 단위로 직접 길찾기)
- 파티클·셰이더 직접 제작 (에셋의 이펙트를 사용)

## 2. 디자인 목표

### 2.1 핵심 유저 체험

| 체험 | 내 게임에서 구현하는 방법 |
|---|---|
| 위치 선정의 재미 (지형, 적과의 거리, 아군과의 간격) | 시야와 엄폐시스템으로 전투에서 유리한 위치가 존재하도록 한다 |
| 무기 선택의 판단 (같은 유닛, 다른 범위) | 상황마다 제한조건과 화력, 감쇄율 등을 다르게 설정  |
| 적의 다음 수를 예상하는 수 싸움 | 전투가 벌어질만한 위치에서 미리 킬존을 생성해두고 유도하도록 하기 |
| 범위 무기로 여러 적을 한 번에 맞히는 쾌감 | 위의 킬존에서 폭발물 등으로 한번에 여러 적을 처리 |
| 마지막 적 격파의 클리어 성취감 | 시작할때 단순 전력상으론 불리한 게임을 전략을 통해 승리할때의 쾌감을 목표로 함 |

### 2.2 디자인 기둥

1. 적 - 실제라면 어떻게 행동하는게 자연스러울지
2. 아군 - 단순히 같은 패턴 반복을 어떻게 방지할지 (폭탄목걸이)

## 3. 게임 플로우

### 3.1 전체 흐름

```text
메인 화면 → 스테이지 선택 → 전투 맵 시작·유닛 배치
  → 아군 페이즈 ──(모든 아군 행동 완료 또는 턴 종료)──→ 적 페이즈 (한 기씩 행동)
  → 승리·패배 조건 확인
      ├ 적 전멸            → 스테이지 클리어 → 결과 화면
      ├ 전투 가능 아군 없음 → 스테이지 실패   → 결과 화면
      └ 계속               → 턴 수 +1 → 아군 페이즈
  ※ 승리·패배 조건은 아군 행동마다 확인
결과 화면 → 다음 스테이지 / 재도전 / 메인 화면
```

### 3.2 아군 유닛 한 기의 행동 순서 (필)
```text
아군 유닛 클릭 → 이동 범위 표시 → 이동할 칸 클릭 (범위 밖이면 취소)
  → 경로를 따라 칸 단위로 이동 → 커맨드 메뉴 (공격 / 대기)
      ├ 공격: 무기 선택 → 공격 범위 표시 → 대상·방향·지점 선택 (취소 시 메뉴로)
      │       → 확정 → 명중·데미지 계산 → 결과 표시 → 행동 완료
      └ 대기: 행동 완료
```

- 이동 취소 후 원래 칸 복귀 (선택) — 구현 여부:
- 턴 종료 버튼으로 남은 유닛을 두고 페이즈 넘기기 (필)

### 3.3 상태 설계

| 구분 | 상태 목록 | 전환 조건 |
|---|---|---|
| 페이즈 | 적 | 모든 적 유닛의 행동 종료|
| 페이즈 | 아군 | 플레이어가 턴 종료 버튼을 누름|
| 페이즈 | 결과 | 게임 중 승리/패배 조건 달성|
| 조작 단계 | 대기 | 선택한 유닛 이동및 행동 불가 / 유닛 선택 페이즈에서 선택 취소|
| 조작 단계 | 유닛 선택 | '대기' 상태에서 조작 가능 유닛 선택됨 / '~ 준비' 상태 취소 / '~ 진행' 페이즈 후 행동력 남아있음 |
| 조작 단계 | 이동 준비 | '유닛 선택' 상태에서 '이동' 버튼 누름|
| 조작 단계 | 행동 준비 | '유닛 선택' 상태에서 '행동' 버튼 누름|
| 조작 단계 | 이동 진행 | '이동 준비' 상태에서 목적지 선택|
| 조작 단계 | 행동 진행 | '행동 준비' 상태에서 타겟(유닛/지점) 선택|

## 7. 이동 범위 (필)

### 7.1 규칙
- 이동력 안에서 갈 수 있는 모든 칸 표시
- 지형별 이동 비용 적용. 진입 불가 칸, 적 유닛 칸은 통과 불가
- 아군 칸은 통과 가능, 정지 불가
- 실제 경로를 따라 한 칸씩 이동 (장애물을 뚫고 직선으로 이동 금지)
- 추가 규칙 : 이동 종료는 정지 가능 지형에서만 가능

### 🧩 설계 질문
- 모든 칸의 비용이 1이면 BFS로 충분하다. 숲처럼 비용이 다른 칸이 섞이면 BFS가 틀리는 경우는? 다익스트라로 바꾸면 무엇이 달라지는가?
  - BFS의 경우 찾은 경로가 최단 경로가 아닐 가능성이 커진다
  - 다익스트라의 경우 노드간의 이동비용을 고려하여 계산하기 때문에 더 많은 노드를 거치더라도 비용이 더 적은 경로를 찾을 수 있다
- 경로 복원을 위해 "어느 칸에서 왔는가"를 무엇에, 어떤 자료구조로 기록하는가?
  - 스택형 자료에 이전 위치를 기록한다
- "통과 가능, 정지 불가" 규칙을 탐색 중 어디에서 처리하는가? (탐색에서 빼기 vs 결과에서 빼기)
  - 결과에서 뺀다 (목적지 선택시 해당 타일의 정지 가능 여부를 확인)

- [x] 단일 대상 (최소~최대 사거리, 칸 거리 기준)

- [x] 부채꼴 (한 칸 나아갈 때마다 폭 2칸씩 증가)

- 맵 밖 / 진입 불가 칸에 걸칠 때:공격 범위 표시에서만 제외하고 이펙트는 동일하게 처리한다
- 직선 무기가 바위에 막히는가: 막힘
- 범위 무기에 아군이 맞는가 (맞으면 사전 경고): O

## 9. 전투 계산 (필)

### 9.1 규칙
- 공격 시 명중 판정, 맞으면 데미지. HP 0이면 맵에서 제거
- 공격 전 예상 감쇄율·예상 데미지 창 표시
- 원형 범위 무기를 제외하고 직선 거리 내에 관통 불가 타일 있으면 공격 불가
- 반격 (추가구현) — 구현 여부와 조건: 공격 가능한 행동력이 남아 있을때 
  공격 가능한 범위에서 적이 공격

### 9.2 계산식
- 폭발공격의 관통 = 중심점에서 1칸 멀어질때마다 1 감소
- 감쇄율 : 탄의 경우 명중률, 폭발의 경우 데미지 감소율에 영향을 준다
  - (장갑 - 관통)이 >=2 : 80% / 1 : 50% / 0 : 0% / <=1 : 0%(지형 파괴) 
- 폭발 데미지 = 데미지 x (1 - 감쇄율)
- 탄 명중률 = 1 - 감쇄율

```
- 점수 = 적이 기관총으로 구조물(약)에 있는 아군을 공격시 
  - 공격타입 : 탄 (명중)
  - 장갑(3) - 관통(1) = 2 (감쇄율 80%)
  - 예상 피해 = 10데미지로 10번 공격 시도, 각 시도당 명중률 : (1-[감쇄율])
- 점수 = 적이 박격포로 엄폐물에 있는 아군을 공격시 
  - 공격타입 : 폭발 (오차 + 피해감소)
  - 50%확률로 목표타일이 아닌 목표 옆 타일 4칸중 1칸을 공격함 
  - 장갑(2) - 관통(2 - (거리감쇄 1)) = 1 (감쇄율 50%)
  - 입는 피해 = 100 * 50% = 50 (회피 불가)
```

| 공세 | 목적지로 이동하며 적이 시야에 들어오면 경계로 전환 | 보병, 중화기 |
| 이동 | 적을 무시하고 목적지로 이동 | 장교 |
